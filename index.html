brighttpd

brighttpd is a small and fast static file server that uses Linux kernel toys like io_uring, splice, and kTLS.

getting started

make
mkdir -p www
printf '<h1>ok</h1>\n' > www/index.html
printf 'not found\n' > www/404.html

umask 077
cat > brighttpd.conf <<'EOF'
listen [::]:8080
root www
EOF

./brighttpd -c brighttpd.conf -n
./brighttpd -c brighttpd.conf

features

  • static file root is indexed at startup; index.html and 404.html are required.
  • GET and HEAD over HTTP/1.0 and HTTP/1.1, with keep-alive and single range queries.
  • io_uring accept/recv/send/read/splice/poll/timeout loop with fixed-file registration.
  • buffered reads for small files, splice for larger plain HTTP responses, kTLS sendfile path for TLS.
  • PKCS#12 TLS config, optional HTTP-to-HTTPS 308 redirects.
  • privilege drop, capability clearing, PR_SET_NO_NEW_PRIVS, seccomp, and connection timeouts.
